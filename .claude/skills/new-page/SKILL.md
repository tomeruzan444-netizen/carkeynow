מכישלון אמיתי שמתועד ב-`worklog/`, והתאריך בסוגריים הוא המקור.

**לקרוא לפני הכתיבה:** `CONTENT_GUIDE.md` ו-`GOOGLE_CONTENT_GUIDELINES.md`.

## שלב 1. כיסוי, לפני שכותבים מילה

```bash
rg -o '"?slug"?: .([^"'"'"']+)' lib/manual-pages.ts lib/wp-pages.ts | grep <עיר או נושא>
git log --oneline --all -i --grep='<עיר או נושא>'
```

**לא מספיק לבדוק שהסלאג פנוי.** לקרוא את כל העמודים הקיימים על אותה
עיר או אותו נושא. (2026-10-25: לאשדוד כבר היה עמוד קודן **שתפס את
זווית המלח והקורוזיה**, ובלי לקרוא אותו הייתי כותב אותה זווית פעמיים.)

אם העמוד כבר קיים: **לא לכתוב שני.** להראות את הקיים ולשאול.
(2026-10-14: בני ברק.)

## שלב 4. כתיבה

לפי `CONTENT_GUIDE.md`. שלושת המינימומים בסעיף 18 הם **רצפה ולא יעד**:
700 מילים, 5 מופעי מילת מפתח, 10 שאלות.

**את מילת המפתח משבצים בכותרת H2, בפתיחת סקשן או בתשובת FAQ.** לא
דוחסים אותה באמצע משפט שלא צריך אותה.

**לכתוב `<strong>` ישירות ולא `**`.** (קרה שלוש פעמים בחודש אחד.)

## שלב 5. השער

לכתוב טיוטה ל-JSON ולהריץ:

```bash
node scripts/content-gate.mjs <draft.json>
```

מבנה הטיוטה מתועד בראש הסקריפט. השער מריץ 33 בדיקות: שלושת
המינימומים, כללי הכתיבה, הקישורים, הכותרות מול **כל** האתר, ייחודיות
השאלות, מדד תבניתיות, והתנגשויות של סלאג, id ושמות משתנים.

**אזהרת מחירים אינה חוסמת.** היא מצביעה על שתי משפחות התמחור שממתינות
להכרעה, ממצא 32 ב-`OPEN.md`.

**לא לכתוב שום דבר לריפו לפני שהשער נקי.**

**צפוי שבדיקת מילת המפתח תיכשל בהרצה הראשונה.** זה קרה עשר פעמים
ברצף. להוסיף מופעים טבעיים ולהריץ שוב.

## שלב 6. סקריפט ההוספה

**לכתוב אותו ישירות. לא לגזור אותו מסקריפט של עמוד קודם.**
(נכשל כך ב-2026-09-24 וב-2026-10-06: שינוי שם משתנה רץ לפני האנקור
שהשתמש בשם הישן.)

הסקריפט מאמת **כל נקודת עיגון כייחודית** לפני שהוא כותב משהו, ואז
עורך: `lib/manual-pages.ts`, `lib/faqData.ts` (קבוע + ניתוב),
`lib/caseStudies.ts`, `lib/visualData.ts` (קבועים + ענף),
`lib/siteData.ts`, `components/Sidebar.tsx` (**בסוף** המערך).

**להעתיק כל עוגן מהקובץ, לא לכתוב אותו מהזיכרון:**

```bash
grep -n '<היצרן או העיר>' lib/siteData.ts components/Sidebar.tsx
```

שתי רשימות הניווט מנסחות את אותו פריט אחרת. (2026-10-29: `siteData`
כותב "שכפול מפתח לרכב סיאט" ו-Sidebar כותב "שכפול מפתח לסיאט",
ושני עוגנים לא נמצאו בהרצה הראשונה.)

להריץ עם `PYTHONIOENCODING=utf-8`, ו**לכתוב את הסקריפט לקובץ ולא
ב-heredoc** אם יש בו regex. שני החסמים האלה נתפסו שוב השבוע.

## שלב 7. בנייה ואימות

```bash
npx tsc --noEmit
npm run build
node scripts/content-verify.mjs <slug>
```

`content-verify` בודק 20 דברים על ה-HTML שנבנה, ובראשם ש**התוכן בכלל
מרונדר**: ארבעה עמודים באתר הם מקרה מיוחד ב-`page.tsx`, ובעמוד צרו קשר
התוכן אינו מרונדר כלל (2026-10-26).

אם הבנייה נכשלת על `next/font`, לבדוק רשת לפני שמחפשים באג:
`curl -I https://fonts.googleapis.com`.
